# 🔐 Password Strength Checker

A simple web application built with **Python and Flask** that checks the strength of a password based on common security requirements.

## 🚀 Features

- Checks password length
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for special characters
- Calculates a password strength score
- Simple and user-friendly web interface

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- Regular Expressions
